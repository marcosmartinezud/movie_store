# Agenda de Contactos (E4b)

SPA en Vue 3 (sin build) lista para desplegar de forma estática.

## Contenido

- `contacts-spa/index.html` — entrada principal
- `contacts-spa/styles.css` — estilos
- `contacts-spa/app.js` — lógica Vue con Vuefire.
- `contacts-spa/firebase-config.js` — Claves para la conexion con firebase.

## Uso local

```bash
cd E4b/contacts-spa
python -m http.server 5173
```

Abrir en el navegador `http://127.0.0.1:5173/`.

## Despliegue

- Direccion de app web desplegada en NETLIFY `https://zesty-chimera-3b59e5.netlify.app/`
